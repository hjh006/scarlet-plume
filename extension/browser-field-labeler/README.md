# 当前页字段标注扩展

在 Chrome / Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。无需授予全部网站权限；只有用户点击扩展并确认授权后，`activeTab` 才允许本次读取当前页。源码 ZIP 解压后同样加载。

1. 在已获授权的业务页面打开所需表单或弹窗，点击扩展，确认当前页授权并读取。
2. 核对来源路径及字段标签，取消不应传递的项。扩展不读输入值、密码、选项值、正文或跨页/后台流量；页面标签仍可能含业务信息，请逐项核对。
3. 粘贴赤翎已登录工作区页面地址，点击“前往平台预览”。字段只通过平台 URL 的 hash 片段传递，不传平台令牌。平台载入后会移除该片段参数。
4. 在平台再次核对页面标识，明确选择实际资产（包括已登记 API 或字段资产），填写人工标识/字段映射并保存。可点击“匹配所选资产OpenAPI字段”，平台对已导入该资产契约中的已识别字段执行名称精确匹配（去首尾空格、不区分大小写），返回带扫描/方法/路由/位置证据的候选。用户逐项选择后保存；无契约或无同名字段保持未知。候选不是运行时关联验证。

标注是人工声明，不证明 DOM 与 API 或数据库字段之间存在血缘，也不自动修改正式分类分级。

每次读取最多100项可见字段。不支持浏览器内部页、跨域 iframe、关闭的弹窗、画布及未渲染虚拟列表；它们是覆盖缺口，不代表不存在数据。需要更多页面时逐页授权读取。当前实现不拦截网络请求，不自动翻页或全站抓取，不持久存储页面内容。

验证：从本目录执行 `npm test`，使用合成 DOM 与 Chrome mock，不连接手册环境。

打包：从仓库根目录执行 `npm run package --prefix extension/browser-field-labeler`。本地构建需要 Python 3；脚本仅用 Python 标准库，将源码 ZIP 写入已有 Vite 静态目录 `governance/static/extensions/browser-field-labeler.zip`。`npm run build --prefix web` 会先自动执行同一打包步骤，随后将 ZIP 复制到 `web/dist/extensions/`。不要手动维护第二份 ZIP 或只复制到 dist。
