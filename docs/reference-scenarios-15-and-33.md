# 15 页测试指引与 33 页场景介绍的能力对照

依据用户本轮提供的《全链路数据风险管理系统：场景测试指引》（15 页）和《全链路数据风险管理系统：场景介绍》（33 页），按封面为第 1 页核对。本文记录赤翎截至 2026-11-12 的实现范围，不将参考材料中的营销描述、案例、准确率、自动插桩或完整覆盖直接视为验收事实。先前 29 页材料的历史说明保留在 [旧版映射](hongtu-capability-mapping.md)，本轮范围以本文为准。

“已实现”只指该行列出的具体技术链路；“有限覆盖”表示关键条件、原始内容或部署范围仍有明确差异。未接入来源、缺失字段、过期观察及未启用采集均保持未知。技术检查必须按授权来源、规则版本、观察窗口和覆盖得出结论，不能把没有风险命中解释为全部合规。

## 15 页测试指引

| 页码 | 参考目标 | 当前实现与入口 | 边界 |
| --- | --- | --- | --- |
| 1 | 封面 | 材料标识 | 无独立功能验收项。 |
| 2 | 分类、资产、流转、调查、风险和态势协同 | 真实资产 ID、发现任务、运行时来源、分类、技术检查、整改及证据报告互相关联 | 已授权来源及明确关联有效；参考 Mall/FineBI 是演示环境，不表示赤翎已适配其客户实例。 |
| 3 | 演示流程 | 分类/资产/图谱/运行时/运营调查/场景检查入口 | 导航存在不代替来源采集及业务条件完成。 |
| 4 | 结构化、非结构化、自定义策略；等级及目录 | 原生数据库和 OpenMetadata；本地文件适配器；关键词/RE2/精确词典；标准原生等级、业务目录和人工确认 | 内置格式类别及文件格式有限；标准指引不等于所有行业规则自动化。企业任意等级体系及复杂布尔识别策略仍需按现有模型适配。 |
| 5 | 个人信息识别、补标、查看结果 | 格式校验、元数据候选、文件命中；规则校准；人工/批量确认；发布导出及台账 | 有限采样，负向结果不降级；主体真实性、用途及法定类别继续取证。 |
| 6 | 浏览器辅助经营字段打标 | 已实现显式浏览器扩展/页面标签提交、经营字段声明及已有 OpenAPI 字段候选映射 | 用户明确选择页面字段；不抓输入值/页面正文，不自动宣称 DOM 与网络字段形成真实血缘，也不自动处理所有弹窗。 |
| 7 | 动态资产目录 | 业务/应用/数据库/表/字段/文件共享资产身份，CMDB 业务属性、修订历史和来源有效性 | 目录范围由授权及实际返回决定；不是全企业自动发现完成。 |
| 8 | 上下游与具体字段数据流 | 当前精确库表目标、应用/API/字段类型、双端 trace/span 调用证据、历史图与差异 | 类别相同不连边，表名歧义保留未知；具体值指纹相同也不自动建立数据血缘。 |
| 9 | 输入具体值追溯来源 | 客户侧 CLI 计算 HMAC，平台按 Token 查询文件位置和运行时字段/接口/审计引用，显示来源时效 | 原值和密钥不提交平台；旧日志无指纹则未知。数据库关联仍须真实 DatabaseTargets/链路证据。 |
| 10 | 允许类别与超范围采集 | `over_collection` 及敏感类别/来源/接口策略，保存版本、窗口、命中分母、风险处理及检查证据 | 对比的是组织配置的允许范围；没有同意记录、隐私政策及业务目的证据时，不自动判定法律上的超范围。 |
| 11 | 密码明文传输风险 | `credential_cleartext_transport`：凭据字段信号与明确 HTTP 传输跳段事实联用 | JSON 中出现凭据字段不等于公网明文；未知 TLS、单个代理跳段或单纯类型命中均需保留范围。 |
| 12 | 敏感数据详细访问日志 | 有界字段统计、来源、主体引用、IP、时间、接口、trace/span 与审计引用，可筛选和导出调查快照 | 不保存完整请求/响应数据或原始敏感值，因此与参考材料的原文日志回放有差异。 |
| 13 | 举报调查与持续风险监控 | 指纹定位、主体/IP/接口/时间筛选、风险策略、处置及冻结运营调查报告 | 提供技术证据及缺口；不由相同主体引用认定现实个人，也不自动形成事实充分的举报结论。 |
| 14 | 关键岗位离岗审计 | 来源内主体引用、访问行为、频次/时段/多 IP 等规则及调查报告 | 岗位、离职状态、工号与主体引用映射需要客户确认；平台不自动决定是否满足离职条件。 |
| 15 | 态势、按范围统计及运营报告 | 已接入来源统计、图谱、资产、风险、检查及按明确 runtime 范围冻结的运营报告 | 保留来源/窗口/单位；不同来源计数不能擅自相加。报告不等于监管机构已接受。 |

## 33 页场景介绍

| 页码 | 场景 | 当前技术覆盖 | 明确限制 |
| --- | --- | --- | --- |
| 1 | 封面 | 材料标识 | 无独立验收项。 |
| 2 | 企业简介、完整实时及全球合规宣传 | 不转化为产品验收结论 | 供应商专利、客户案例、全球法律覆盖及效果描述不由本仓库验证。 |
| 3 | 引导/筑底/支柱/管理 | 场景技术检查、分类资产、流转图、检查与运营报告 | 咨询、组织建设及管理充分性需要现实业务证据。 |
| 4 | 应用探针与统一平台部署 | 客户侧发现器、应用清单、HTTP/HTTPS 代理、已有 OTLP 探针、事件桥接 | 不是任意语言内部函数的通用免改造自动探针。 |
| 5 | “有什么数据”分隔页 | 见分类与发现 | 无新增功能。 |
| 6 | 浏览器标签、接口匹配、九十余识别策略 | 明确页面字段标注、OpenAPI 辅助候选、本地规则和格式校验 | 不承诺九十余种同等识别器、业务语义识别效果或自动全接口匹配。 |
| 7 | “在哪里”分隔页 | 见资产目录 | 无新增功能。 |
| 8 | 动态资产管理 | 周期采集、来源修订/时效、字段/库表及文件目录、责任属性和变更留痕 | 只覆盖已授权对象；不宣称源数据此刻没有变化。 |
| 9 | 高频及失活资产 | 运行时计数、API 生命周期及观察时间的有限窗口统计 | 窗口外无流量不等于业务已废弃；没有十万/百万接口规模性能等效验收。 |
| 10 | “如何流转”分隔页 | 见图谱与追踪 | 无新增功能。 |
| 11 | 应用与数据库流转 | 来源精确目标、调用证据及类型/字段线索 | 元数据所有者不等于 ACL，数据库系统类型不等于具体表或具体值来源。 |
| 12 | 指定数据在不同节点流转 | 指纹筛选访问记录、明确 trace/span 双端链路、显式转换关系 | 同指纹仅支持等值关联；缺少父子链或实际目标时不能推出真实流转路径。 |
| 13 | 通过可见类型判断数据库未加密 | **不采用该推断**；PostgreSQL 可另行记录本次采集连接实际 TLS 状态、协议和密码套件 | 证据来自已建立 pgconn 连接，旧记录 nil 保持未知。只描述采集器到已配置端点这一跳；类型可见与数据库存储加密可以同时存在，静态加密有效性仍未知。 |
| 14 | 加密状态下链路闭环 | 显式客户侧 crypto-transform SDK/JSON 契约：真实调用前后 HMAC、同来源已保存审计 trace/span/时点绑定、查询两侧匿名关系 | 需要授权插桩或显式声明；不能无改造通用解密，也不把源声明升级为数据库加密有效或真实自然人认定。 |
| 15 | “谁在使用”分隔页 | 见主体调查 | 无新增功能。 |
| 16 | 用户/IP/国家/时间与详细请求响应 | 有界审计记录、来源内主体引用、直接观察 IP、客户声明国家及字段统计 | 不保存请求响应原文；国家不是自动 GeoIP 结果，主体引用不是自然人证明。 |
| 17 | 按泄露具体值追人 | 客户本地 HMAC Token 查询文件/运行时及相关显式转换记录 | 无原文回放、无历史指纹追补；没有命中不证明从未发生访问。 |
| 18 | 时间、次数、数据量和基线异常 | 固定版本的频次、错误率、时段、允许类别及显式业务量阈值规则 | 配置阈值不是学习到的正常基线；请求次数不等于记录条数或去重人数。 |
| 19 | 多人共用账号 | 来源内同主体多 IP 观察与策略 | 多 IP 可能来自代理/移动网络，不证明多人；没有真实用户关联时保留缺口。 |
| 20 | 异地登录 | 同主体多国家声明、声明地区与配置范围比较 | 不调用 IP 地理定位，不把地区变化自动判定为被盗号。 |
| 21 | 非工作时间访问敏感数据 | 可配置时段、时区偏移和类别/来源范围 | 组织工作日、节假日、轮班及例外授权需要客户提供。 |
| 22 | 少量多次/超范围获取 | 主体累计/重复访问、类别允许范围、版本与实际窗口证据 | 请求量不自动转换为人数、数据量或恶意意图。 |
| 23 | 导出监测 | 可记录来源声明的操作目的、业务量/单位、主体、接口、字段类别，并按配置规则分析 | 不保存导出文件正文；未提供导出标识或业务量时不能把任意 GET 或大响应自动认定为导出。 |
| 24 | 告警对接工单/SOC | 已有安全事件接入/桥接、受控处置及分类发布交付接口 | 入站事件、分类发布交付和风险告警出站是不同契约；任意工单厂商主动告警推送仍需按实际接口适配。 |
| 25 | 多种安全工具协同 | Wazuh/规范事件、有限代理阻断、PG 直接 SELECT 撤销/回滚、专项评估及证据报告 | 不是通用加密、水印、任意访问控制设备的策略执行器。 |
| 26 | 实践章节分隔页 | 见后续场景 | 无新增功能。 |
| 27 | 共享链路及非约定目标 | 实际调用图、来源声明接收方/目的地及配置范围策略 | 未观察外部目的地、授权协议或真实接收方时不能宣称完整共享链。 |
| 28 | 共享详细日志 | 时间/IP/接口/目的地声明、字段类别和 HMAC 证据引用 | 不存共享正文；未采集部分保持未知。 |
| 29 | 共享超范围/超量 | `recipient_scope`、`destination_scope`、`over_collection`、`volume_limit` 与检查/报告 | 比较的是明确配置及来源声明；缺少量纲、协议允许范围或业务量时不通过推断补齐。 |
| 30 | 跨境接口识别 | 目的地 IP/域名/国家声明、配置范围变化及跨境检查与报告材料衔接 | 网络目的地声明不等于已核实物理跨境；IP 类型、格式命中或域名不能单独决定出境义务。 |
| 31 | 跨境日志 | 同范围运行时摘要、来源/去向声明、时间、指纹及冻结调查/检查报告 | 不保存跨境数据正文，不宣称全量跨境流量覆盖。 |
| 32 | 再次备案提醒 | 来源/活动/分类修订、变更重评、范围/目的地/类别/量的技术变化线索及证据缺项 | 已备案基线、适用路径、实际人数/数据量及监管要求需核实；技术变化不自动形成再次备案的法律结论。 |
| 33 | 结束页 | 材料标识 | 无独立验收项。 |

## 可复查证据与交付口径

- 文件、具体值与转换关系：[文件内容及指纹说明](file-content-and-value-evidence.md)、[采集回归](../backend/internal/collector/discovery_files_test.go)、[真实文件 Store 链路](../backend/internal/store/catalog_discovery_files_test.go)、[源端 JSON 指纹](../backend/internal/runtimesecurity/value_fingerprint_capture_test.go)、[实际 AES-GCM SDK](../backend/pkg/cryptoevidence/transform_test.go)、[绑定审计来源与查询](../backend/internal/store/crypto_transforms_test.go)、[HTTP 凭据及原值拒绝](../backend/internal/httpapi/value_fingerprints_test.go)。
- 分类标准、模型接入、规则及人工发布：[标准库](classification-standards.md)、[分类工作台](classification-workbench.md)。AI 建议、检索知识及自定义规则训练须分别按其实际协议和测试范围说明，不能称为已有机器学习效果验收。
- 现有运行时、主动验证、受控修复与报告：[运行时](runtime-security.md)、[API 验证](api-validation.md)、[安全运营](security-operations.md)、[技术场景检查](technical-scenario-checks.md)。
- PostgreSQL 连接证据：[真实 TLS/非 TLS 与旧记录未知回归](../backend/internal/collector/postgresql_transport_test.go)。只有当前来源、配置修订和新鲜度均有效时，技术检查采用该观察说明连接状态；不增加默认通过项，也不替代静态加密、完整访问控制或恢复验证。

新 PPT 应明确区分：技术能力已实现、已用合成夹具验证、尚需客户实例验收。准确率/召回率、OCR 质量、全链路覆盖、吞吐/延迟/资源消耗和供应商兼容性需使用实际授权对象清单、带标注语料及目标部署环境单独验收。本轮未访问供应商环境，也不以有限测试替代这些效果指标。
