# Windows 企业终端部署与验收记录（2026-11-13）

本轮完成固定原生控制的代码、平台协议、部署包和合成验收；没有可用的 Windows 企业测试机。Windows 的硬件效果、兼容性、PowerShell 安装运行、SCM 服务生命周期和企业 GPO/MDM 环境验收仍为 **pending / not_run**。交叉编译、配置回读和协议夹具不替代这些验收。

## 本轮交付

- Windows x64、ARM64 执行器与企业部署 ZIP，由 Docker 从公开源文件和当次构建的二进制生成；包含显式目标模板、安装/移除脚本、静态核验脚本和功能验收清单。
- 安装脚本从管理员指定的平台 HTTPS origin 取得独立发布清单，先核对受保护暂存文件的 SHA256，再执行配置和服务注册。直接使用服务安装命令时也必须提供独立批准的 `-expected-sha256`；包内哈希不是代码签名。
- 固定 SYSTEM 服务，独立来源与设备标识，机器 DPAPI 配置和恢复记录，SYSTEM/Administrators 受保护目录、创建时 Owner/DACL 及跨进程独占锁。SYSTEM 服务不观察用户登录会话的剪贴板。
- 平台迁移 048：固定能力与目标摘要、独立批准、稳定租约/操作引用、分阶段回执、撤销/过期恢复命令、冻结 HTML/JSON 证据。
- 设备页分别展示准备、配置、回读、功能验证、恢复、冲突与失败；没有该阶段证据时保持未知。撤销不直接宣称恢复成功。

## 实际范围

| 控制 | 范围 | 仍需验证的效果 |
| --- | --- | --- |
| USB | Windows 可移动存储类拒写策略 | 授权设备上的实际 I/O、生效与重启/重开要求；不是全部 USB 协议 |
| 打印 | 模板中明确列出的本地打印队列暂停 | 队列调度与恢复；在印任务可能继续、新任务仍可能入队 |
| 剪贴板 | RDP 剪贴板重定向限制 | 授权会话重连后的双向重定向；不覆盖本地应用间剪贴板 |

注册表控制遇到 AD 域、MDM、归属未知、原值已配置或权限不足时保守拒绝接管。打印队列的同值外部操作有原生可观测性限制，应由管理员协调独占管理。原生 API 可能阻塞，不承诺硬实时恢复。

## 已执行的验证

- 全量 Go `go test -race -p 1 ./...`，提供独立真实 PostgreSQL 测试 DSN；`go vet ./...` 通过。依赖其他外部连接器 DSN 的用例没有因此变为全环境覆盖。
- Windows amd64、arm64 的源端 vet、构建和 PE 架构核验；额外 386 编译检查通过。只分发 x64/ARM64。
- 真实 PostgreSQL + HTTP 集成：来源登记、独立批准、准备/配置/回读、重启不重复执行、撤销命令、内存驱动恢复及冻结导出保持不变。驱动为合成夹具，没有调用 Windows 系统 API。
- 原生状态机与恢复反例：准备回执未接受则不写入；TTL 不能开始下一目标；Stop 等待在途动作；部分成功仅恢复已封存项；崩溃不确定区间和丢失原值日志均不猜测所有权；离线回执重传不重复动作。
- 打包器测试覆盖明确白名单、符号链接拒绝、架构/格式/限额负例、原子写入、旧产物保留、ZIP 与独立 manifest 的内容/哈希一致性。未将来源令牌、机器配置或测试账号打包。
- Vue 类型检查、构建及 7 项场景上下文测试通过；1600、1366、1280 桌面宽度核对无整页横向溢出，浏览器未记录错误。独立合成库中完成 JSON 冻结导出和撤销，功能验证保持缺失，撤销显示等待源端回滚。
- 本地 Docker app 更新到迁移 048，健康检查 204；保留原有四个网络以及 Wazuh、OpenMetadata 等集成服务。主库未加入合成终端验收设备。
