# 企业数据与AI安全能力

本文件说明数据安全、AI应用安全和Agent安全的功能、接入方式与能力边界。外部目录、网络设备和安全服务可作为明确授权的观察或执行来源，具体支持范围取决于连接器和部署配置。

## 八方向入口与可操作结果

| 方向 | 入口 | 功能与采用范围 |
| --- | --- | --- |
| 数据发现与分类 | 发现、分类工作台 | 原生数据库、受授权文件与目录接入，候选识别、人工确认、发布、分类质量和来源当前性；不把候选升级为已确认类别。 |
| 数据安全态势管理 | 安全能力工作台 | 汇总当前分类、责任团队、受控PostgreSQL权限暴露和来源缺口，按明确规则排序，冻结快照及导出。PUBLIC权限表示数据库授权条件，不表示互联网公开。 |
| 数据流向与使用治理 | 数据流转与处理活动 | 业务登记、API/网关/OTLP与明确数据库目标、历史快照与差异；声明和实际观察分开，网络关联支持登记与变更复核。 |
| AI资产与供应链治理 | AI安全工作台 | 应用、主体、知识文档、模型、工具和策略的工作区配置、修订、独立发布及评测门禁；登记的供应商与地域信息不替代厂商实际处理位置证明。 |
| AI数据安全 | AI知识与调用策略 | 基于可信源ACL在检索前授权，结合文档分类和请求内容检查模型外发，检查模型输出；只覆盖已接入执行点和已支持的格式、规则。 |
| AI运行时防护 | AI调用与客户侧代理 | 配置版本、输入/输出限制、限定模式检测和允许/拒绝决策，固定上游转发；识别规则的效果由测试集说明，不声称识别所有语义攻击。 |
| Agent/MCP安全 | 工具授权与客户侧代理 | 工具、动作、资源目标与参数约束，高影响动作独立批准、有效期、请求摘要绑定与重放保护；需客户将相应工具执行路径接入。 |
| 持续评测与安全运营 | AI评测、决策证据与运营页面 | 正反用例实际运行、配置版本冻结、发布门禁、决策元数据、审计、处置复测与报告；策略评估与真实执行回执分别采用。 |

## 三条执行链

### 数据权限到RAG检索

客户端凭证绑定实际应用和主体，客户端不能自行指定ACL或可信身份。配置记录文档版本、ACL版本、允许主体及数据类别；正文位于客户侧文档来源。未授权、禁用、未知或失效对象在返回正文前拒绝。应验证跨主体、跨应用、文档撤销及旧权限缓存等反例。

### 数据使用限制到模型请求

采用固定模型目标和可信分类信息，检查应用/主体、允许类别、处理地域、输入输出大小和明确规则。拒绝请求不得到达模型上游；受限制的输出不得先交付后记录。协议、超时、审计失败、重定向、截断和不支持格式都需要明确结果。控制台“评估”不表示客户侧已经实际阻断。

### 业务授权到工具动作

工具执行使用服务端配置的目标，不接受客户端自选URL。授权绑定应用、主体、动作、目标、参数及配置摘要。高影响批准独立产生，并在期限、参数和配置一致时采用；重放和失效批准拒绝。执行失败与成功分开留证，不能以Agent声称成功替代真实副作用。

## 网络与业务关联

`/api/v1/workspaces/{slug}/security-platform`统一展示八方向记录、来源范围、风险及网络关联。

- 网络关联包括站点、线路、VRF、应用引用、已存在的数据资产和处理活动、登记地域、接收方、用途及证据引用。
- 手工关联一律标记`declared`。对未知设备、缺失日志或未接入的线路保留缺口。
- 变更影响复核冻结关联修订和受影响对象。独立Owner/Reviewer可接受或驳回复核；自审、重复复核及关联修订变更后沿用旧批准均被拒绝。
- 接受复核不改变设备，也不表示数据已经按新路径传输。设备变更和真实AI调用效果需要对应来源回执与新观察。
- 快照采用数据库一致性视图，冻结来源、范围、风险和登记关系，保留摘要；导出快照不会重新计算为当前状态。

## DSPM 资产范围与分页核对

“数据风险与证据”通过 `GET /api/v1/workspaces/{slug}/security-platform/posture` 遍历资产，可核对概览前250项以外的对象。工作区成员可读取；查询始终校验工作区成员身份。

- `q` 按资产名称、系统、责任团队和来源引用作文字匹配；`severity` 可选 `high`、`medium`，`code` 可选页面列明的风险类型。
- `limit` 为1至100，默认50。`cursor` 使用响应中的不透明 `nextCursor`，切换范围或风险条件后重新查询。
- `assets` 是本页实际核对的资产，`items` 是其中匹配条件的发现。`matchingAssets` 表示所选资产范围，不能当作风险数量或来源覆盖率。筛选后没有发现但 `hasMore=true` 时仍须继续翻页。
- 游标固定本轮资产ID上界，排除后来新增的资产；每页按读取时的分类及权限事实计算，不构成跨页冻结快照。刷新查询纳入新增资产。
- 页面导出仅重新读取当前页，保留生成时间、资产上界、核对对象及覆盖说明。概览及其冻结快照仍有各类记录上限，查看快照内的 `truncated` 和 `coverage`，不可将其称为全组织完整清单。

个人权利、同意撤回、供应商监督、审计、事件报告及内容标识采用[治理办理](governance-operations.md)关联实际活动与证据；自动报告的用途保护、保全和独立解除见[报告留存](report-retention.md)。

## 验证与范围

每条能力分别记录：配置、实际接入、策略评估、真实执行、独立复测。客户未提供真实来源时不能自动升级状态。采样、条目上限、截断、陈旧和失联均属于覆盖范围，不把缺失观察理解为没有风险。

通用连接器需要按实际厂商、版本、数据格式与客户授权验收；用户SSO、第三方知识库的完整ACL语义、模型后台保留/训练用途、Windows实机效果及未接入终端，都不能由控制台页面或本地合成测试推导为已验收。

执行器测试命令见[运行时验证](ai-security-runtime.md#verification)，控制面数据库测试见[控制面验证](ai-security-control-plane.md#验证)，发布门禁见[版本化回归](ai-security-regression.md)。部署后还应以实际身份、资料源、模型和工具核对允许、拒绝、撤销及故障路径，并检查运行回执；缺少环境或跳过用例应明确记录。
