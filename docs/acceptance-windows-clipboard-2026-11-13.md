# Windows 本地剪贴板代码与验收包（2026-11-13）

本轮交付代码、平台证据链和企业部署包 v2。首轮应用验收范围为 Office（Word/Excel）、Edge/Chrome、记事本；没有执行它们在 Windows 企业终端上的实际复制/粘贴、兼容性或性能验收。清单十项均默认 `not_run`。

## 已交付

- 当前交互用户的原生变化监听：启动已有内容不读，无有效独立批准不读新正文；只在源端做有界 Unicode 文本格式识别，上传 HMAC 引用、分类和状态。
- 当前实例条件清除：同一用户/输入桌面、窗口站、短期一次性票据、序号与 owner 再核对；内容替换、占用、过期或归属未知则跳过或保留未知。
- 应用主动接入 `session-copy`/PowerShell helper 时，复用真实写入前检查和受控阻止；原生 Ctrl+C 继续属于变化后响应，不能推导为全部应用粘贴前拦截。
- 独立 `session_response` 策略及迁移 049：单登录会话目标、独立审批、TTL、源撤销/会话变化永久结束、loaded/stopped 回执、匿名 intent/result、HTML/JSON 冻结导出。事件不混入风险清除/G03复测链。
- 当前用户 DPAPI 配置、当前用户/SYSTEM 私有 ACL、独立来源、低权限交互用户运行、可选登录任务、停止请求和仅元数据重传；与 SYSTEM/RDP 机器控制分开。
- v2 ZIP 包含 14 个公开文本资产、x64/ARM64 两个执行器及 manifest；独立发布清单描述 16 个文件哈希。包中不放运行配置、来源令牌、真实账号或测试数据库。

## 已完成的验证

- 独立真实 PostgreSQL 下的全量 Go race suite、host vet；最终源端命令包的 race、amd64/arm64 Windows vet，以及原生部分 amd64/arm64/386 编译检查通过。
- 真 PostgreSQL/HTTP + 内存驱动：独立审批、部分 Office 文本确定命中、先持久化意图再调用驱动、逐次响应、离线补传幂等、撤销停止后续动作，以及冻结导出不被后续状态改写。
- 原生 fake/纯测试：startup baseline、无批准时零正文读、序号/owner/线程/身份/5秒票据、混合表示、延迟渲染变化、正文内存清理、清后空回读与未知分离。用户易失会话代际在 helper 重启时复用，正常重启/hive卸载后变化。
- 并发/期限反例：监听与策略到达两种顺序均先持久化 loaded 回执才采用；同一批准不因时钟回退或过期后重新收到 bundle 而重获期限；清除意图为最终结果预留队列预算，审计不可用则不开始动作。
- PowerShell 源的限定静态复核覆盖 bootstrap 哈希顺序、同份有界 bytes 校验与复制、来源标记保留、路径重解析/硬链接、ACL、参数数组、秘密清理、任务身份和停止确认。CI 另配置 Windows PowerShell 5.1 parser 与 Windows 纯函数/ABI 用例；它们不执行安装、任务登记、真实剪贴板读取或清除。
- Vue 类型检查/构建及 1600、1366、1280 三种桌面宽度核对通过；合成工作区展示清除、stale、busy、partial无命中unknown，JSON冻结和撤销后等待来源停止。主工作区没有加入这些合成设备。
- 本地 Docker app 更新到迁移 049，健康检查204，保留原有四个网络及其他集成容器；下载 ZIP 的条目、文件哈希、独立 manifest 与 PE 架构一致性已核对。

## 效果边界与实机验收

通知发生在内容变化后，其他应用可能在清除之前读取或粘贴。清后 empty 只证明持锁当时的当前剪贴板为空；Windows 历史、云同步副本和应用缓存不因此消失，正文不会被持久化用于恢复。非文本或额外 HTML/自定义表示不因文本命中而变成已完整识别，缺失分母与快速变化遗漏保持未知。

原生延迟渲染/消息可能阻塞，不承诺硬实时响应。撤销需源端收到；离线不会延长采用的固定 TTL。当前进程使用单调期限和批准墓碑，重启后仍重新校验服务端绝对有效期与会话目标；企业环境须保持正常校时。配置属于当前用户，不宣称防该用户篡改或驱动级强制控制。

PowerShell 安装/DPAPI/ACL/登录任务的实际运行，以及十项应用/恢复功能清单仍需授权 Windows 企业测试机执行。参考[部署说明](../endpoint/windows-enterprise/README.md)、[十项功能清单](../endpoint/windows-enterprise/clipboard-functional-checklist.csv)与[原生接口契约](windows-clipboard-session.md)。
