# AI 安全版本化回归与升级门禁

引擎诊断、测试包、配置修订和发布资格分别记录。测试包只引用服务端已登记的合成探针，不保存任意提示词、真实请求/响应正文或密钥，不调用客户模型、工具和知识源。

## 使用流程

在“AI 运行时安全 → 策略回归”载入平台基线，核对完整 JSON，进行服务端校验预览，再明确导入冻结版本。选择包运行当前已保存配置，检查用例、派生契约与覆盖缺口，最后由不同于配置修改人的 Owner/Reviewer 独立复核发布。

校验预览只计算并检查，不落库。已有声明摘要必须匹配；修改包内容时需使用新版本，明确移除旧摘要后重新计算。导入必须带有效摘要，并携带该包族上一个版本 `expectedLatestVersion`；新族为空。相同包族/版本不可覆盖，旧版本继续保留。

## 22 个注册探针与覆盖采用

平台基线涵盖身份边界、请求时效、RAG、模型、工具及明确停用六类维度。服务器根据当前启用的能力要求具体探针，包自报维度不能代替通过结果：

- 未知应用；每个启用能力的正向范围或独立审批门槛、未知主体、过期请求及未知目标。
- 已知应用撤销主体授权、已知主体撤销应用授权两个方向的绑定。
- 已知文档撤销已知主体 ACL，防止“只测未知文档”掩盖 ACL 校验退化。
- 实际模型选择覆盖与数据类别到固定模型目标限制。
- 已知工具的越权动作、目标和参数；独立于高影响审批门槛检查，避免“仍被审批拒绝”掩盖其他授权校验被删。
- 所有登记应用明确 disabled 时的拒绝模式。它可以发布安全停用状态，不表示业务可用。

八个探针采用**派生引擎契约**：只在内存复制目录、撤销一项授权，或隔离一个目标/参数约束，运行同一真实决策引擎。该副本不保存、不发布、不执行上游；它与原目录的当前范围正反例分别标识。派生测试清除可掩盖目标控制的文本规则，部分工具测试关闭副本中的高影响属性以单独验证动作/目标/参数。结果需要符合明确的拒绝代码，不能用另一个更早的拒绝替代该边界的验证。

`expectedOutcome` 支持 `allow`、`deny`、`configured`。后者采用目录声明的可用范围和审批门槛；高影响预期来自可信 `Tool.highImpact`，不采用引擎自报“是否需要审批”决定预期。原配置诊断也必须通过，改变包预期不能将原诊断失败洗为通过。

未启用范围标记 `not_applicable`；启用范围缺少正例或必选探针、超预算及实际失败均阻断门禁。当前每个启用资产族至少构造一个可用范围，候选预算为 8192；它不是对所有主体、资产和业务组合的穷举。合法客户对象使用旧探针保留名时，也会选择确认不存在的探针标识，避免名称碰撞误锁。

## 发布与比较

新的发布必须同时满足：当前配置修订及摘要、当前引擎和检测版本、当前包族的最新冻结包、完整必测探针、通过结果及独立复核。导入新包版本后旧回归仍保留，但不能用于新的发布。已有部署不会因导入测试包而自动被重新配置或撤销。

发布事务与包导入在工作区范围串行核对最新包，发布前立即重跑门禁并记录复核时点，避免采用评测后已经过期的主体/文档授权。真实执行点仍在调用前及释放内容前检查权限，控制台复核不能替代客户侧检查。

比较使用同工作区冻结结果和稳定用例 ID：用例增加、移除、定义/探针/预期变化单独列示；只有定义未变、从通过变成实际失败才计入 `regressions`。不适用转换不等同检测退化，旧诊断不能冒充版本化比较。结果不包含模型准确率、供应商兼容性或生产效果的推断。

## 接口与限制

接口前缀为 `/api/v1/workspaces/{slug}/ai-security`：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /regression-packs?before=...&limit=50` | 分页读取冻结包摘要，附 hasMore/nextCursor；保留支持维度及当前受支持门禁/引擎/检测版本元数据。 |
| `GET /regression-packs/export` | 导出本次过滤分页摘要及明确 scope，不包含全部包内容。 |
| `GET /evaluations?before=...&limit=50&status=passed` | 评测历史分页；status 可为 passed/failed。 |
| `GET /evaluations/{id}` | 原样读取该历史评测及其已记录版本，不重新计算发布资格。 |
| `GET /regression-packs/baseline` | 完整基线包。 |
| `GET /regression-packs/{id}` | 工作区内完整冻结包。 |
| `POST /regression-packs/validate` | `{pack}`，校验并计算摘要，不保存。 |
| `POST /regression-packs` | `{expectedLatestVersion, pack}`，CAS 导入。 |
| `POST /evaluations` | `{packId}` 运行版本化回归；`{}` 仅运行 legacy 诊断，不能新发布。 |
| `GET /evaluations/{id}/compare?against={oldId}` | 同工作区冻结结果比较。 |
| `POST /publish` | 沿用 `{expectedRevision,evaluationId,note}`，服务端验证全部门禁条件。 |

读取沿用工作区权限；校验、导入与运行需要 Owner/Operator，发布需要独立 Owner/Reviewer。写接口沿用 Origin 防护。每包最多 128 用例、256 KiB；每工作区最多 1000 冻结包，列表默认 100、显式页长 1—200，使用工作区/集合绑定的 nextCursor 作为下一页 before。分页及导出范围见[控制面操作说明](ai-security-control-plane.md#历史读取与分页导出)。重复 JSON 字段、非法编码、超预算、未知字段、未注册探针、错维度、重复用例 ID 和不符摘要拒绝。

包摘要为去除 `digest` 后按现有服务器规范 JSON 计算 SHA-256，不使用客户端字符串字节直接签名。服务器预览提供同一算法结果；数据库读回和发布时再次验证摘要。

更新标签、用例集合、预期和包版本可以复用当前引擎；增加新探针语义、协议或检测器需要新的受测引擎发布。平台不自动从互联网下载执行测试或放宽策略。实际工具定义 pin、真实模型响应、知识源 ACL 同步及运行性能继续通过执行器与客户环境验收。
